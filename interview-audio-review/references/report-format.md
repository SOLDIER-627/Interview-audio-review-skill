# 面试复盘报告格式

除非用户指定其他格式，否则使用下面的结构。报告语言默认与面试语言一致，也可以使用用户指定的语言。

## 输出文件

输入文件为 `interview.m4a` 时，最终只输出：

- `interview.review.md`：处理说明、证据限制、问答还原、纠错记录、逐题评价和推荐答案合并后的最终报告。

不得直接覆盖已有报告；同名文件存在时生成 `interview.review-YYYYMMDD-HHMM.md` 或递增版本。

原始转写 JSON、修复转写、音频分片、基准片段、纠错稿和分析草稿只放在本次临时目录。最终报告验证通过后清理该目录，不把这些文件保存到录音目录。

## 临时证据层

处理中，每个临时原始转写片段尽量包含以下字段：

```json
{
  "start": 125.4,
  "end": 131.8,
  "speaker": "说话人 A",
  "text": "语音识别模型的原始输出",
  "confidence": null,
  "source_chunk": "interview.part-001"
}
```

如果转写后端没有提供置信度，使用 `null`，不得自行编造分数。

临时证据层必须保留到最终报告完成并通过检查，便于核对问答、纠错和不确定片段。它不是最终交付物。

## 最终 review.md

### 1. 处理与证据说明

开头注明：

- 源文件和时长；
- 使用的转写后端，或已有转写稿的来源；
- 是否产生新增费用；
- 使用的模型、设备和是否启用说话人分离；
- 预处理、转写、角色处理、分析和总耗时；
- 语音识别实时系数，以及是否达到约二十分钟处理一小时录音的目标；
- 处理日期；
- 说话人角色映射及置信程度；
- 缺失、损坏或不可靠的音频范围。
- 分片长度、重叠时长、发生局部重试的范围，以及重试后仍不可靠的范围；
- 本次只持久化最终 `review.md`，其余中间产物已清理。

### 2. 总体结论

说明面试类型、有效问题数量、整体表现模式、最强项、最大风险和三个优先改进方向，并披露证据限制。

### 3. 问答还原与逐题评价

按时间顺序逐题列出。每个问题先展示忠实问答，再展示模型理解、评价和推荐答案：

```markdown
## Q1. <问题短标题> [00:02:05–00:03:01]

**面试官问题（还原）**

<经过纠错的完整问题>

**我的回答（忠实还原）**

<只做高置信度纠错，不优化内容>

**我想表达的核心意思（模型理解）**

<简短理解，明确这是模型理解>

**评价**

| 维度 | 分数（1–5） | 依据 |
|---|---:|---|
| 切题程度 | | |
| 表达结构 | | |
| 正确性与深度 | | |
| 证据与影响 | | |
| 沟通表现 | | |

**做得好的地方**

<具体优点>

**主要问题与面试官可能的顾虑**

<内容缺口、风险表述或歧义>

**推荐回答（短版）**

<忠于真实经历、适合口头表达的答案>

**可能追问与准备要点**

<追问和需要如实补充的信息>
```

重要追问使用 `Q1.1` 等子编号。问候、流程沟通和候选人反问可在单独小节概括，不纳入评分。

### 4. 实质性纠错与不确定片段

最终报告内附纠错表：

| 时间 | 原始文本 | 纠正文本 | 原因 | 置信度 |
|---|---|---|---|---|

只有标点变化且不影响含义时，不需要记录。另列不确定片段：时间范围、问题类型、是否重试及最终处理方式。Whisper 在静音或思考停顿生成的重复短语不得列为候选人原话。

### 5. 跨问题诊断

总结多道问题中反复出现的内容和表达模式，引用问题编号和时间戳。

### 6. 优先练习计划

根据已观察到的弱点给出三到五项具体练习任务，优先提供回答结构、需要补充的真实信息和模拟问题。

## 完成与清理条件

- 最终文件名以 `.review.md` 或带版本号的 `.review-<版本>.md` 结尾；
- 文件位于原录音目录，不位于本次临时目录；
- 至少包含“处理与证据说明”“总体结论”“问答还原”“推荐回答”；
- 每个评分问题都有时间戳、忠实回答和评分依据；
- 报告中包含实质性纠错表和不确定片段；
- 报告写入并验证后，使用 `cleanup_run.py` 删除本次临时目录；
- 清理后，本次运行在录音目录中只新增最终 review 文档。

## 证据规则

- 录音证据使用时间戳。
- 简历、岗位说明或笔记应标注为“用户提供的背景材料”。
- 外部事实必须给出引用，且不得改变候选人在录音中真正说过的内容。
- 推荐答案可以重新组织已知事实，但不得创造个人事实。
- 如果完整答案依赖缺失信息，必须使用醒目占位符，不能猜测。
- “只保留 review”不等于省略证据边界；原始文本与优化答案的区分、纠错记录和不确定范围必须在最终报告中可见。
